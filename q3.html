Comparing Typesettings

Typesetting, Desktop Publishing, HTML, and CSS

Old fashion typesetting was done mannually by arranging indivitual metal character and printing plates, which made the process more time consuming and labour-intensive. In desktop publishing, designers can create and edit documents quickly by using computer software and other design tools. HTML and CSS are a more modern way of publishing content to the web. HTML is mainly for the structure of the content, while CSS is mainly for the presentation and appearance. It is with HTML and CSS that webpages can adapt to different devices and screen sizes.
