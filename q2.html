1. Appearance The most notable difference is the appearance of a google doc, and an html doc. To write a google doc, you'd most likely be writing on the Google Docs software, whether online or on your device. Writing an html doc would usually require a specified software or program, such as a code space on GitHub. 2. Purpose Google docs and html docs serve different purposes. A google doc would mainly be used just for any sort of writing, notes, etc. An html doc's purpose is to build a web page specifically designed to be displayed on the internet. 3. Functions Google docs and html have different functions built in for changing the appearance of how text is displayed. For example google docs, you can use ctrl functions to make bold or italicized text. Whereas in an html doc, you can use semantic tags or formatting tags.
